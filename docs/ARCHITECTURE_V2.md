# SPHARX 架构设计文档 V2

## 🏗️ 整体架构

SPHARX采用双轨流水线架构，同时处理2D图像和3D几何数据，最终生成包含物理属性的多模态数据集。

### 架构图

```
┌─────────────────┐    ┌─────────────────┐
│   2D图像轨道    │    │   3D几何轨道    │
├─────────────────┤    ├─────────────────┤
│  图像预处理     │    │  点云预处理     │
│  自动标注(SAM)  │    │  三维重建       │
│  标签优化       │    │  几何优化       │
└─────────┬───────┘    └─────────┬───────┘
          │                      │
          └─────────┬────────────┘
                    │
         ┌──────────▼──────────┐
         │   2D→3D标签提升     │
         │   (Cross-modal)     │
         └──────────┬──────────┘
                    │
         ┌──────────▼──────────┐
         │   物理属性生成      │
         │   (Physics-aware)   │
         └──────────┬──────────┘
                    │
         ┌──────────▼──────────┐
         │   数据集组装        │
         │   标准化输出        │
         └─────────────────────┘
```

## 📊 组件详解

### 1. 预处理模块 (01_preprocess)

**功能**：统一数据格式，执行基础清洗

**输入**：
- 原始图像文件
- 点云数据
- 相机参数

**输出**：
- 标准化图像 (RGB, 1024×1024)
- 清洗后的点云
- 统一坐标系

### 2. 2D标注模块 (02_2d_annotation) ⭐【优先级最高】

**功能**：基于SAM的自动图像标注

**核心技术**：
- Segment Anything Model (SAM)
- 提示工程优化
- 批量处理加速

**输出**：
- 图像分割掩码
- 边界框标注
- 类别标签

### 3. 3D重建模块 (03_3d_reconstruction)

**功能**：从多视角图像重建3D几何

**技术栈**：
- COLMAP (SfM)
- Open3D (点云处理)
- MeshLab (网格优化)

**输出**：
- 稠密点云
- 三角网格模型
- 纹理贴图

### 4. 标签提升模块 (04_2d_to_3d_lifting)

**功能**：将2D标签投影到3D空间

**关键技术**：
- 相机位姿估计
- 2D-3D对应关系建立
- 投影一致性优化

**输出**：
- 3D语义标签
- 实例分割网格

### 5. 物理生成模块 (05_physics_generation)

**功能**：推断物体物理属性

**推断属性**：
- 质量分布
- 材质属性
- 摩擦系数
- 弹性模量

**方法**：
- 基于形状的启发式推理
- 材质数据库匹配
- 物理仿真验证

### 6. 数据组装模块 (06_dataset_assembly)

**功能**：整合所有模态数据

**输出格式**：
```json
{
  "metadata": {...},
  "images": [...],
  "pointclouds": [...],
  "meshes": [...],
  "annotations": {
    "2d": {...},
    "3d": {...}
  },
  "physics": {...}
}
```

## 🔧 技术选型

### 核心框架
- **Python**: 3.9+
- **深度学习**: PyTorch
- **Web框架**: FastAPI
- **容器化**: Docker + Docker Compose

### 关键依赖
- **SAM**: Facebook Research
- **COLMAP**: 视觉SLAM工具
- **Open3D**: 3D数据处理
- **CVAT**: 图像标注平台

## 📈 性能指标

### 处理能力
- **图像处理**: 1000张/小时
- **3D重建**: 10场景/天
- **标签提升**: 500帧/小时
- **物理推断**: 200物体/小时

### 资源需求
- **CPU**: 16核以上
- **GPU**: RTX 3090 (24GB)
- **内存**: 64GB
- **存储**: 2TB SSD
